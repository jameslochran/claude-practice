# Contributing

Thanks for taking a look at this repo! It's a small practice project, so
contributing here is meant to be low-friction.

## Getting started

1. Fork or clone the repo.
2. Create a branch for your change:
   ```
   git checkout -b my-change
   ```
3. Make your edits.

## Making a change

- Keep pull requests small and focused on one thing.
- Write a clear commit message explaining *why* the change was made, not just
  *what* changed.
- If you're adding something new, a short note in the README is welcome but
  not required.

## Opening a pull request

1. Push your branch:
   ```
   git push -u origin my-change
   ```
2. Open a pull request against `main` describing what you changed and why.
3. Don't worry about being perfect — this is a practice repo, and feedback is
   meant to be quick and friendly.

## Questions

If anything here is unclear, feel free to open an issue and ask.
